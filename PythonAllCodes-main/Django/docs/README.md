# Docs

This folder contains documentation and course material for the repository. The goal is to keep documentation centralised so you can create additional independent projects/ folders at the repository root without clutter.

Structure:

- `Django_MET_Syllabus.md` - Markdown-converted copy of the original Django syllabus.
- `originals/` - Archive of original unmodified documentation files.

Guidelines:

- Add any other documentation files to this folder. Use subfolders (for example, `tutorials/`, `references/`) to keep things organized.
- When adding new projects, create a top-level folder (for example, `projects/my_new_project/`) and keep project-specific docs inside the project folder or in `docs/` if they are cross-project.
