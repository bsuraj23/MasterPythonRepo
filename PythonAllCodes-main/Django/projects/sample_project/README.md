# sample_project

Minimal scaffold for a new project. Use this as a starting point for creating additional projects under `projects/`.

Contents:

- `README.md` — project description
- `requirements.txt` — pinned dependencies for this project (empty by default)
- `.gitkeep` — placeholder so the folder is tracked

How to use:

1. Copy this folder or use the script in `../scripts/create_project.ps1` to create a new project.
2. Create or activate a virtual environment and add dependencies to `requirements.txt`.
