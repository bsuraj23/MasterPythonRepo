# django_demo — Django demo umbrella project

This project contains small apps for teaching Django topics. Start the dev server and explore the demo apps:

Example URLs (after running dev server):

- / -> core index
- /templates/ -> templates demo
- /forms/ -> forms demo
- /models/ -> models demo
- /auth_demo/ -> auth demo
- /views_demo/ -> views demo
- /ms/ -> middleware & signals demo
- /state/ -> state (cookies/sessions/cache) demo
- /advanced/ -> advanced demos
